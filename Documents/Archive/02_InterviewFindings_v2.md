# Needs

- **Urgency & Risk Guidance**
    - User needs clear urgency guidance (incl. calibrated labels).
    - User needs safety guidance (what to do immediately).
    - User needs benchmarks/reference points (normal vs abnormal).
    - User needs decision support under uncertainty.
- **Reporting & Communication**
    - User needs guidance on how to describe problems clearly.
    - User needs to send complete, structured information upfront.
    - User needs automated message generation (clear, calm, structured).
- **Documentation & Evidence**
    - User needs a checklist of required information (what to capture & include).
    - User needs clear evidence guidance (what + how to document).
    - User needs organized, time-based documentation (photos, notes, progression).
- **Case Management & Tracking**
    - User needs persistent case tracking (history, proof, timeline).
- **Problem Framing & Routing**
    - User needs issue categorization (e.g., mold, leak, electrical).
    - User needs routing guidance (who to contact).
- **Guidance Quality**
    - User needs simple, non-technical guidance.
    - User needs trustworthy guidance.

---

# Pains

- **Uncertainty & Decision-Making**
    - User struggles to assess urgency and risk.
    - User cannot distinguish normal vs serious problems.
    - User fears making wrong decisions (underreacting/overreacting).
    - User lacks expertise to act confidently.
- **Reporting Friction**
    - User doesn’t know how to report issues properly.
    - User struggles to describe issues clearly.
    - Reporting requires multiple back-and-forth exchanges.
    - Missing or unclear information leads to follow-ups.
- **Documentation Gaps**
    - User is unsure what evidence to provide.
- **Process Inefficiency**
    - Lack of continuity/history causes repeated effort.
    - Process feels inefficient and frustrating.
- **Trust & Relationship Issues**
    - User feels blamed or must justify themselves.
    - Issues are dismissed without strong evidence.
    - Advice from others can feel unsafe or unreliable.
- **Emotional Impact**
    - High uncertainty creates stress and anxiety.
- **Coordination Issues**
    - User is unsure who to contact.

---

# Insights

- **Core Problem Space**
    - Urgency & risk assessment is the core friction point.
    - Core tension: acting correctly under uncertainty.
    - Uncertainty blocks action and drives anxiety.
- **Structure & Efficiency**
    - Lack of structure creates inefficiency and iteration.
    - Structured outputs reduce cognitive load.
- **Evidence & Credibility**
    - Evidence collection is critical but unclear.
    - Documentation quality directly impacts credibility.
    - Problems are underestimated without strong evidence.
- **Time & Continuity**
    - Lack of history resets progress and weakens cases.
    - Time-based tracking (progression) is essential.
- **User Capability Gap**
    - Users operate outside their expertise → need guidance.
    - Decision-making is hindered by lack of benchmarks.
- **Process Gaps**
    - Contact/routing decisions are unclear.
    - Categorization is a key step in problem framing.
- **Trust & Dynamics**
    - Users seek accountability and proof over time.
    - Relationship with landlord can feel adversarial.
    - Simplicity and clarity increase trust.
